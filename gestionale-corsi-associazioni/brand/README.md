# Regestio — brand assets

Generati dal marchio della landing (DM Serif Display, glifi convertiti in tracciati → gli SVG non dipendono da font installati).

## Colori
- Verde marchio: `#2e8b57`
- Verde scuro (wordmark su chiaro): `#0e1f16`
- Bianco: `#ffffff`

## File
| File | Uso |
|------|-----|
| `icon.svg` | Icona master (R su quadrato verde), scalabile |
| `icon-1024.png` / `icon-512.png` / `icon-256.png` / `icon-192.png` / `icon-32.png` | Icona rasterizzata. **Stripe → icona attività**: usare `icon-512.png`. `icon-32` = favicon, `icon-192` = apple-touch-icon |
| `logo.svg` / `logo.png` (h512) / `logo@256.png` | Logo orizzontale (icona + "Regestio"), wordmark scuro, sfondo trasparente. Per sfondi **chiari**. **Stripe → logo** (ricevute/fatture): `logo.png` |
| `logo-white.svg` / `logo-white.png` (h512) | Stessa lockup con wordmark bianco, per sfondi **scuri** |

## Stripe (Dashboard → Impostazioni → Brand)
- Icona: `icon-512.png`
- Logo: `logo.png`
